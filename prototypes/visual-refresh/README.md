# 视觉修复方向评审稿

这是 HeroUI 方向（[ADR-0012](../../docs/决策/ADR-0012-视觉方向改为HeroUI风格.md)）的**修复版评审稿**，不是新的视觉方向，也不属于 `src/` 正式应用。

直接打开 [`index.html`](./index.html) 即可并排检查浅色／深色下的：

- 紧凑面板（popover）。
- 主窗口本地用量页。
- 设置页（主窗口子路由）。

只修四类已确诊问题：ok 档黑色进度条、大读数字号失衡、层级（canvas／阴影）不显、排版细节碎。信息架构、状态语义和 [ADR-0019](../../docs/决策/ADR-0019-读数位改用定宽短码与紧凑倒计时.md) 的定宽短码保持不变。

额度与费用取自实机截图的真实数据，不是合成示例。

稿内标 🚩 的取值推翻了现行文档结论，**尚未定稿，不是样式真值来源** —— 真值仍是 `src/styles/tokens.css` 与[设计方向与状态规范](../../docs/设计方向与状态规范.md)。
