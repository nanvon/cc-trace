# 主窗口用量页 · 评审草图

本目录是 [ADR-0020](../../docs/决策/ADR-0020-主窗口改为本地用量页.md) 的评审草图，用于确认主窗口用量页的**布局与信息层级**。

## 这是什么，不是什么

- 单个静态 HTML，无构建、无依赖、无网络请求。
- 不属于 `src/`，不连接 Rust command，不读取 `usage.db`，不读取凭据。
- 页内全部为**假数据**，只保证内部自洽（两个 Provider 相加等于总数，模型分组小计相加等于合计）。
- 柱状图是 CSS `div`，不是 ECharts。正式实现的图表选型见 ADR-0020 第 7 节。
- **不含交互**：日期档、排序表头、Provider 卡片均无点击行为。排序语义见 ADR-0020 第 4 节。
- 它不代表主窗口已实现，也不构成任何平台的验证证据。

## 直接打开

```bash
open prototypes/usage-page/index.html
```

跟随系统浅色／深色外观，切换系统主题可看两套配色。

## 草图里已确定的事

| 内容 | 结论 |
|---|---|
| 页面顺序 | 筛选行 → 总览读数 → 按 Provider → 每日花费 → 按模型 |
| 总览读数 | 只有总 Token 与总花费；不显示输入／输出／缓存维度 |
| Provider | 左右并排，不上下堆叠 |
| 价格粒度 | 只到 Provider 与模型，不按 Token 类型拆分 |
| 模型表 | 一套表头 + 两个 Provider 分组，分组行带小计 |
| 分类色 | 彩色只给 Provider，其余中性 |
| 数量单位 | 中文界面用万／亿，数值与单位分设字号 |

## 草图里尚未确定的事

- **缓存命中率的分母**：现取 `缓存命中 ÷ (输入 + 缓存命中 + 缓存写入)`，页内的 84.0% / 86.2% 由此得出。口径未定，见 ADR-0020「未解决问题」。
- **`<$0.01` 与「未定价」**：`claude-haiku-4-5` 行是前者（已定价但金额极小），`codex-auto-review` 行是后者（价格目录未覆盖，按 [数据存储与用量索引](../../docs/数据存储与用量索引.md) §3 不得当作 `0`）。两种写法待确认。
- **额度异常解释的落脚点**：主窗口不再显示额度，草图中也没有它的位置。见 ADR-0020「未解决问题」。

## 与 `tray-shell` 的关系

[`prototypes/tray-shell/`](../tray-shell/README.md) 是第 8 阶段的双平台交互原型，验证窗口职责与状态表达，其中的主窗口部分按 ADR-0020 已经作废。本目录只覆盖主窗口用量页，不重复验证 Tray、紧凑面板与首次启动。
