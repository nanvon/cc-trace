# Tray Shell 交互原型

这是第 8 阶段使用的独立低保真原型，不属于 `src/` 正式应用，也不包含 Provider、凭据读取、真实刷新或持久化。

直接打开 [`index.html`](./index.html) 即可检查：

- macOS Menu Bar／Windows Tray 等价入口。
- 浅色／深色。
- 成功、加载、无凭据、离线旧快照、429 和单 Provider 错误。
- 紧凑额度面板。
- 单页主窗口。
- 独立设置窗口。
- 首次启动窗口。
- 键盘焦点、`Esc`、长文本和窄窗口。

所有额度与时间均为合成示例数据，不代表真实 Provider 返回。
