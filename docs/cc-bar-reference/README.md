## 证据等级

- **代码已确认**：当前仓库源码直接实现或声明的行为。业务事实以它为准。
- **测试已确认**：测试代码明确断言的行为；本次没有运行测试进程。
- **文档声称**：产品、技术、设计或布局文档中的意图；不自动代表当前实现。
- **合理推断**：由代码结构、调用关系或资源引用推出来的结论，仍需在新版设计中重新确认。
- **待确认**：静态源码无法证明、依赖真实 Provider / 真机 / 系统权限或需要产品选择的事项。

每个重要结论都尽量标注证据等级和相对源码路径。看到“文档声称”与“代码已确认”不一致时，先看 [09-源码核查清单与文档冲突](09-源码核查清单与文档冲突.md)。

## 新版边界

现有跨端草案已确认：新版是独立的新仓库、新应用、新数据目录，面向 macOS 和 Windows，技术方向为 Tauri 2 + Vue 3 + TypeScript + Vite + Rust + Pinia + Vue Router。新版不复制 Swift/Xcode 工程，不读取或迁移旧 cc-bar 自己的 UserDefaults、额度缓存、Usage/Conversation Rollup、Scan State、导入账号、安全存储项、悬浮窗位置或 Onboarding 标记；可以在产品授权后读取 Codex / Claude Code 的外部凭据和原始日志。详见 [08-跨端复用决策矩阵](08-跨端复用决策矩阵.md)。

## 阅读约定

- 文中的 `~/.codex`、`~/.claude`、Keychain 和 `Application Support/CCBar` 是源码里的通用路径语义，不是本机绝对路径，也不应复制到新版作为数据迁移入口。
- 所有额度和用量结论都是静态代码审计结果；没有调用真实 Provider、读取真实凭据、运行 App 或进行真机验收。
- `CCBarTests` 的断言是行为基线，不代表完整覆盖率，也不代表本次已验证编译通过。
- 现有工作区在审计开始前已经有 `docs/README.md` 修改，以及若干未跟踪的跨端/品牌文档；本次参考资料只新建本目录，不覆盖那些用户已有改动。
