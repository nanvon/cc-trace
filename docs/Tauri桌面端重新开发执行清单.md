# 全新 Tauri 跨端桌面应用执行清单

> 目标：在独立新仓库中，使用 Tauri 2、Vue 3、TypeScript 和 Rust，从零实现一个 macOS / Windows 桌面应用。
>
> 新应用不是当前 Swift 版 cc-bar 的重构分支或原地升级，不迁移、不读取、不删除旧 cc-bar 应用数据。当前 cc-bar 只作为业务事实、Fixture 和问题经验的参考来源。
>
> 本文写于产品名称确认之前，因此正文沿用“新应用”这个说法；它指的就是 CC Trace。

## 文档放置与路径约定

将本文件和方案文档复制到新仓库的 `docs/` 目录。推荐让新仓库与当前 `cc-bar` 仓库位于同一父目录。

本文所有路径都以**新仓库根目录**为基准：

| 路径 | 含义 |
|---|---|
| `.` | 新应用仓库根目录 |
| `docs/` | 新应用自己的文档 |
| `../cc-bar` | 当前 Swift 版 cc-bar 源码仓库，只读参考 |

旧版应用入口为 `../cc-bar/CCBarApp.swift`，核心业务代码位于 `../cc-bar/Core/`。文档不记录个人电脑的绝对路径。

如果新仓库最终没有与 `cc-bar` 放在同一父目录，复制后应统一调整 `../cc-bar`。新应用的源码、构建、测试和 CI 不得依赖旧仓库存在。
