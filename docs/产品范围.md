# CC Trace 首版产品范围

> 状态：已确认
> 目标版本：`0.1.x`
> 基线日期：2026-07-25

## 范围原则

首版验证两个相互隔离的本机闭环：额度路径安全发现凭据、获取并标准化 Provider 额度；用量路径只读扫描 Codex、Claude Code 自身的本地 JSONL，建立可恢复索引并返回脱敏聚合。任一路径失败不得阻断另一条。

没有进入本文件“首版必须”的能力，不创建业务模块、不预留空页面，也不作为首版验收项。

## 首版必须

### 桌面壳

- macOS Menu Bar 与 Windows System Tray 常驻入口。
- 平台等价的紧凑额度入口。
- 可打开、重新打开和聚焦的主窗口。
- 正常退出与开机自动启动。
- 新旧应用可同时运行。

### Provider 与额度

- 自动发现本机当前 Codex 凭据。
- 自动发现本机当前 Claude Code 凭据。
- 展示两个 Provider 的主要额度、必要的专项额度、剩余百分比和重置时间。
- 展示最近成功刷新时间。
- 手动刷新与可配置的自动刷新间隔。
- 请求节流、429 退避和 Provider 间故障隔离。
- Provider 失败时保留 CC Trace 自己的上一份有效快照。
- Codex／Claude Code 官方服务状态点：读取 OpenAI／Anthropic 公开 Statuspage 状态链，
  在紧凑面板每个 Provider 卡头部显示圆点（`unknown` 不显示），tooltip 提供说明与更新时间；
  与额度三维状态是两条独立状态链，见 [ADR-0026](决策/ADR-0026-Statuspage状态链进入首版.md)。

### 展示状态

展示状态按活动、快照新鲜度和失败原因三维组合，语义与转换规则见 [状态与错误模型](状态与错误模型.md)。首版必须覆盖以下状态：

- `loading`：首次加载或主动刷新中。
- `live`：本次刷新成功的当前数据。
- `stale`：刷新失败后保留的上一份有效快照，或快照过期而尚未刷新成功。
- `no_credentials`：未发现可用凭据，不显示伪造的 `0%`。
- `unsupported`：凭据存在但形式不受首版支持，说明支持范围。
- `offline`：明确无法联网且存在或不存在快照。
- `rate_limited`：触发 429 且处于退避期，保留快照并给出可再次尝试时间。
- `error`：凭据、协议或其他不可归为离线的失败。

### 基础设置

- 中文、英文和跟随系统。
- 浅色、深色和跟随系统。
- 自动刷新间隔：`1`、`2`、`3`、`5`、`10` 分钟，默认 `2` 分钟；首版不提供关闭自动刷新。与 [cc-bar 参考](cc-bar-reference/01-产品定位与功能清单.md)候选值和默认值一致。
- 开机自动启动。
- 隐私模式：紧凑入口隐藏账号标识；仅 UI 隐藏，不承诺隐私隔离（cc-bar F-24 边界）。
  关闭时显示完整账号，见 [ADR-0025](决策/ADR-0025-非隐私模式显示完整邮箱.md)。
- 手动更新公开价格目录；请求中防重复，失败继续使用旧价。
- 重新计算用量：设置页「用量与计价」组提供「重新计算用量」按钮，二次确认后删除本地用量
  统计并全量重扫，修复缺失或过期的费用数据；命令层支持按数据源重建，UI 首版只提供全量入口，
  见 [ADR-0027](决策/ADR-0027-本地用量数据重建进入首版.md)。
- 服务状态圆点开关：默认开启，只控制紧凑面板圆点显示，后台 5 分钟拉取不受开关影响，
  见 [ADR-0026](决策/ADR-0026-Statuspage状态链进入首版.md)。
- 版本信息。
- 首次启动的最小状态检查与权限说明。

### 数据与安全

- 使用 CC Trace 独立的数据目录、设置文件和额度缓存。
- 持久化格式从第一版包含 `schemaVersion`。
- 首次启动完成标记保存在 CC Trace 自己的设置文件，不读取外部或 Swift 版 cc-bar 的标记。
- 缓存采用原子写入；损坏时安全回退或重建。
- 外部凭据只在 Rust 层按最小范围读取；来源与平台差异见 [额度领域模型](额度领域模型.md) 第 5 节。
- 对外部凭据的唯一写入是 token 刷新结果原子回写同一个来源，只更新 token、过期时刻与 Provider 自有刷新元数据（Codex `last_refresh`），见 [ADR-0014](决策/ADR-0014-token刷新结果回写外部凭据.md)。
- Vue 只接收额度快照、用量聚合、扫描状态和展示状态；额度身份（完整账号）是唯一例外，
  边界见 [ADR-0025](决策/ADR-0025-非隐私模式显示完整邮箱.md)。
- 普通日志、前端状态和额度缓存不得包含 access token、refresh token、Cookie 或凭据原文。
- Codex、Claude Code 原始 JSONL 只读；CC Trace 不修改、截断、移动或删除这些外部日志。
- CC Trace 在自己的 `usage.db` 中保存 Token 事实、Fast 计费等效 Token、对话元数据、扫描
  水位与额度历史；公开在线价格缓存单独保存为 `pricing-catalog.json` v2。
- 标准化 Token 必须区分未缓存输入、输出、推理输出、缓存读取、5 分钟缓存写入和 1 小时缓存写入。推理输出是输出子集，不重复计入总量。
- API 等值费用只按公开目录估算相同 Token 的 API 标价，不代表 Codex／Claude 订阅实付、账单或发票；未知模型、速度或价格返回“未定价”，不得按 `0` 处理。
- 价格目录合并随应用升级的内置规则与 LiteLLM／models.dev 在线 Standard／Fast 费率；
  24 小时常规刷新，缺价时立即刷新，同一缺价键 30 分钟冷却，失败保留旧价。
- 数据库、command、普通日志和诊断信息不得包含外部 JSONL 绝对路径、原始消息正文、明文项目路径、邮箱、account id 或任何秘密；唯一例外是额度身份的完整账号字段，见 [ADR-0025](决策/ADR-0025-非隐私模式显示完整邮箱.md)。

### 本地用量与历史

- 增量扫描 `~/.codex/sessions`、`~/.codex/archived_sessions` 与 `~/.claude/projects` 下的 JSONL；只消费完整换行行。
- 首次索引后台执行，提供进度、取消、部分失败与断点续扫；缺少任一数据源时其结果为空，不把它升级为全局错误。
- 文件缩短或前缀指纹变化时安全重扫；同一逻辑事件依靠稳定去重键和数据库唯一索引去重。
- 提供按时间、Provider、模型、速度聚合的用量查询，以及带分页的对话列表与单个对话聚合详情。
- Fast 用量同时返回原始 Token、计费等效 Token、倍率范围和无法安全确定倍率的标志；不得
  用等效 Token 覆盖原始 Token。
- 紧凑入口在各 Provider 主额度旁展示 Token 用量的今日／本周 API 等值费用；完成引导后立即
  执行首次扫描，之后每 5 分钟自动增量扫描，紧凑入口不提供手动扫描按钮。额度刷新不触发扫描；扫描中
  保留上一份完成结果，并在费用末尾显示小号灰色 loading。未索引、部分失败、未定价和数据库
  暂不可用不得伪装成精确 `$0`。
- 记录 Provider 成功刷新时额度整数值的变化，按不可逆身份指纹隔离历史；相同值不重复追加。
- 主窗口是本地用量页，不显示任何额度读数。顶栏为标题＋右上（日期快捷八档分段、扫描状态与
  手动刷新按钮）；自定义日期范围选择器在 `custom` 档显示。下方依次为 KPI 总览行（总 Token／
  总花费／各可见 Provider 花费，带前一个等长区间环比 delta，[ADR-0029](决策/ADR-0029-主窗口与对话页对齐cc-bar的功能与布局.md)）、
  Token 拆分面板（总 Token hero＋输入／输出／缓存命中堆叠条＋命中率＋Fast 汇总）、
  各 Provider 矮宽卡（花费＋总 Token＋Token
  分类两行＋缓存命中率）、按 Provider 堆叠的每日用量图（柱高按 Token 数），以及一套表头各 Provider 分组的按模型明细表
  （模型／输入／输出／缓存命中／缓存写入／总 Token／花费七列）。结构与理由见
  [ADR-0020](决策/ADR-0020-主窗口改为本地用量页.md)、[ADR-0024](决策/ADR-0024-主窗口分组侧边栏导航.md)、
  [ADR-0028](决策/ADR-0028-全部表面改为贴合式弱化卡片层级.md) 与
  [ADR-0029](决策/ADR-0029-主窗口与对话页对齐cc-bar的功能与布局.md)。
- 主窗口导航为左侧分组侧边栏：视图组（用量／对话／时间线）＋数据源组（全部／Codex／Claude
  Code／Pi／OpenCode）＋设置钉底；数据源选中是全局内存态，跨页面共享、重启回到全部；进入设置
  时隐藏数据源组。见 [ADR-0024](决策/ADR-0024-主窗口分组侧边栏导航.md)。
- 主窗口同时提供独立的额度历史（Timeline）视图：基于 `quota_events` 表做曲线＋表格可视化，
  每个 Provider 只展示活动序列（最新事件点所属身份与窗口），主账号镜像去重到序列级。它是历史
  读数，不是当前快照读数；用量页本体仍不显示任何额度读数。功能与信息层级对齐 cc-bar
  `QuotaTimelineAccountPanel`（2026-08-10）：面板窗口徽标（5H／WK／MODEL／CURRENT）、
  Current／Today／Latest 三指标、余量四档状态色数据点、Y 轴四档边界刻度、
  Time／Change／After／Reset 四列表格（`resets_at` 来自事件时点快照，schema v6）。范围与边界见
  [ADR-0020](决策/ADR-0020-主窗口改为本地用量页.md) 第 8 节。
- 主窗口同时提供独立的 Conversations 视图：左列表右详情分栏（[ADR-0029](决策/ADR-0029-主窗口与对话页对齐cc-bar的功能与布局.md)）。
  列表支持标题／项目搜索、项目筛选菜单（脱敏项目名，最近活动排序）、Provider 筛选（与侧边栏
  数据源组联动）、时间范围（与用量页共享）、Recent／Tokens／Cost 排序与分页；行内展示
  Provider、标题、项目、模型、速度徽标与最后活动时间、请求数、Token 与费用。详情展示
  全生命周期（起止、时长、请求数、对话 ID 可复制、git 分支）、Token 构成、费用、速度档位与
  按模型明细。只返回脱敏身份与聚合事实，不保存或返回消息正文。参考 cc-bar F-17。
- Codex／Claude Code 对话标题来源（对齐 cc-bar `ConversationTitleIndex`）：Codex 取
  `~/.codex/session_index.jsonl` 的 `thread_name`，Claude Code 取 `~/.claude/history.jsonl`
  的 `display`，索引缺失时分别用 JSONL 内 `user_message` 事件与 `user` 行首条纯文本兜底；
  见 [ADR-0029](决策/ADR-0029-主窗口与对话页对齐cc-bar的功能与布局.md) 与
  [数据存储与用量索引](数据存储与用量索引.md) §4.1。
- Pi coding agent 用量数据源：增量扫描 `~/.pi/agent/sessions/` 的会话 JSONL，会话自带
  `cost` 字段、不走价格表（不参与价格目录、缺价刷新与重计价）；消息时间优先
  `message.timestamp`，归日按机器本地日历日；entry id@时间戳作为全局去重键。读取协议、
  字段语义、去重与价格口径见 [Pi数据源](Pi数据源.md)。
- OpenCode coding agent 用量数据源：只读扫描 `~/.local/share/opencode/opencode.db`
  （SQLite，Desktop／CLI 共用），`message.time_created` 做增量水位、`message.id` 去重，
  官方 `cost` 为费用总额真值、不走价格表（不参与价格目录、缺价刷新与重计价）；
  无订阅额度，只进本地用量统计。读取协议、字段语义、去重与价格口径见
  [OpenCode数据源](OpenCode数据源.md)。
- 统计页按服务过滤：设置页「统计服务」组（Codex／Claude Code／Pi／OpenCode，默认全开），
  关闭的服务从用量页 KPI 与 Provider 卡、每日柱图、按模型表与对话列表统一过滤，占比与
  总量分母只计可见服务（归一化），全关时显示空态引导。参考 cc-bar F-28。

## 首版简化

- 紧凑入口只提供额度概览、今日／本周 API 等值费用、状态和刷新操作，不承载 Token 明细、
  Conversations、复杂筛选、图表或诊断信息。
- 主窗口用量页为顶栏、KPI 总览行（含 delta）、Token 拆分面板、按 Provider、每日用量、按模型
  六段结构。按模型／速度的自定义筛选不进入本轮，也不预留空导航或占位卡片。额度历史（Timeline）
  与 Conversations 是主窗口的独立视图，见 [ADR-0020](决策/ADR-0020-主窗口改为本地用量页.md) 第 8 节与
  [信息架构与核心流程](信息架构与核心流程.md) §6.4～6.5，入口在侧边栏视图组。
- 首次启动只做凭据发现、权限说明和结果反馈，不做长流程教学。
- Provider 只支持当前自动发现的一个 Codex 身份和一个 Claude Code 身份，不提供账号编辑或切换。
- 额度缓存仍只保留每个 Provider 的最新有效快照；额度历史由 `usage.db` 的独立事件表承担，不把两者合并。
- Conversations 首版只提供对话身份、脱敏项目提示、标题、时间范围、模型、速度档位和 Token／费用聚合，不保存或返回消息正文。
- 日期归属固定使用扫描时机器的本地日历日；首版不增加重置时间设置。后续改变只重算派生列，不重扫 JSONL。
- 开发阶段发布 `0.x` 构建；GitHub 自动打包可提前创建 Draft Release，签名与安装器边界由
  [工程与发布](工程与发布.md) 拥有。自动更新仍在公开分发前单独设计和验收。

## 后续版本评估

以下能力不进入首版，只有形成独立产品价值、数据边界和验收标准后才实施：

- 原始对话正文阅读与全文检索。
- 自定义价格、订阅实付归因、账单／发票核对。
- 多图表联动、任意归日边界、数据导出与长期归档策略。首版只有一张按 Provider 堆叠的每日用量图。
- 其他 Codex 账号导入、切换和管理。
- 桌面悬浮窗。
- 高级诊断。
- 按模型、速度的自定义筛选与数据导出。日期范围选择器已进入首版，见
  [ADR-0020](决策/ADR-0020-主窗口改为本地用量页.md)。
- Provider 扩展和团队能力。
- 自动更新。

## 明确不做

- 读取、迁移、覆盖或删除 Swift 版 cc-bar 的设置、缓存、索引、历史、账号或安全存储项。
- 应用内 Provider 登录。
- 浏览器 Cookie 自动导入。
- 通过 WebView 抓取 Provider 网站。
- 修改 Codex、Claude Code 的原始日志，或修改凭据中 token、过期时刻与 Provider 自有刷新元数据之外的任何内容（token 刷新回写是唯一例外，见 [ADR-0014](决策/ADR-0014-token刷新结果回写外部凭据.md)）。
- 将凭据发送到 CC Trace 自己的服务器。
- 为兼容旧版而保留无价值字段或旧页面结构。
- 旧版与新版之间的数据同步。
- Codex Personal Access Token：首版只支持自动发现的 OAuth 凭据。
- Claude Code 的 CLI 交互式额度兜底与 delegated refresh。
- Codex Reset Credits 查询。
- Antigravity 或任何第三个 Provider。
- 修改、清理或修复 Codex／Claude Code 原始 JSONL。

以上 Provider 侧边界的理由与依据见 [额度领域模型](额度领域模型.md) 第 3.3、5.1 节。
Statuspage 状态链原列于“明确不做”，已由 [ADR-0026](决策/ADR-0026-Statuspage状态链进入首版.md) 纳入首版。

## 首版数据来源与验收

| 能力 | 数据来源 | 首版验收 |
|---|---|---|
| Codex 凭据发现 | Codex 自身的本机凭据来源 | Rust 能发现可用状态；Vue 不能取得凭据原文 |
| Claude Code 凭据发现 | Claude Code 自身的本机凭据来源 | Rust 能发现可用状态；Vue 不能取得凭据原文 |
| Provider 额度 | Provider 实时接口 | 能标准化主要额度、重置时间和刷新时间 |
| 错误恢复 | 请求结果与 CC Trace 最新有效快照 | 刷新失败后明确显示 `stale`、`no_credentials`、`offline`、`rate_limited` 或 `error` |
| 本地设置 | CC Trace 独立设置文件 | 重启后保留，损坏时回退到安全默认值 |
| 额度缓存 | CC Trace 独立额度缓存 | 原子写入，包含 `schemaVersion`，不读取旧版缓存 |
| 本地用量 | Codex／Claude Code 自身的本地 JSONL | 完整行增量扫描、截断／改写恢复、稳定去重；原始日志保持只读 |
| 用量重建 | `usage.db` 中的派生统计与扫描水位 | 设置页二次确认后全量重扫，重建前后各数据源总量一致；官方直存 cost 源（Pi、OpenCode）的上游修正可被重新采纳 |
| Conversations | 同一 JSONL 的脱敏身份与时间元数据 | 可分页查询，不保存或返回消息正文、绝对路径或明文身份 |
| Pricing／费用 | 内置政策 + LiteLLM／models.dev v2 缓存 + 标准化 Token | Standard／Fast 在线补价；缺价触发与手动更新；已定价行返回 API 等值费用，未知价格返回未定价；更新价格只重算 SQLite |
| 额度历史 | 成功的 Provider 额度快照 | 只记录整数变化，按身份指纹隔离；数据库恢复优先保全 |
| 主窗口用量页 | `usage.db` 聚合查询 | 日期区间可选；总量、Provider 分项与模型分组三层数字互相对得上 |
| Tray / Menu Bar | Tauri 与平台适配层 | 两个平台都可查看概览、刷新并打开主窗口 |

## 首版完成标准

- macOS、Windows 均能安装或启动开发构建，显示系统区域入口并打开主窗口。
- Codex、Claude Code 在存在凭据时能独立刷新并展示额度。
- 单个 Provider 失败不会阻断另一个 Provider。
- 加载、成功、无凭据、离线、旧快照、刷新受限和错误状态完整。
- 触发 429 时保留已有快照、展示可再次尝试时间，且退避期内不持续发起请求。
- 新旧应用同时运行时，应用身份、数据目录和安全存储互不影响。
- 首次索引可报告进度、取消并从已提交水位恢复；单个损坏文件不阻断其他文件或额度路径。
- Codex 与 Claude Code 的脱敏 JSONL Fixture 能验证标准化 Token、重复事件、半行、截断、同尺寸改写和聚合查询。
- 价格目录更新只重算相关数据库派生费用；未知价格、Fast／Priority、计费等效 Token、倍率
  与地域假设在查询契约中可区分。
- 紧凑入口按 Provider 展示今日／本周 API 等值费用；存在已定价记录时显示当前可计算金额，
  不追加金额下限符号或未定价说明；全部无法定价、未扫描或读取失败时显示占位。
- `usage.db` 损坏时保留数据库文件组并重建可派生数据；额度历史尽力导出恢复，不静默删除。
- 设置页「重新计算用量」二次确认后全量重建：各数据源重建前后汇总一致；OpenCode 官方 cost
  补写后重建能把费用补齐；扫描中触发重建给出明确失败提示。
- 主窗口用量页在八个日期档与自定义区间下都能返回结果；KPI 总览行（总 Token／总花费／各源花费，
  含 delta）与各 Provider 卡分项数字纵向对账一致，Token 拆分面板堆叠段与 KPI 总 Token 一致，
  模型表的分组小计相加等于合计行；侧边栏数据源选中单个源时页面所有区块只显示该源数据且纵向对账仍成立。
- 手动刷新按钮在扫描中禁用并显示扫描状态，扫描完成后用量数据更新；紧凑入口不出现该按钮。
- 对话列表标题与项目提示可搜索；项目筛选菜单只列出当前范围内有对话的项目；分栏点击行后
  右侧展示同一对话详情，详情含对话 ID（可复制）与分支；Codex／Claude 对话标题来自
  索引文件与消息兜底两级（见 [ADR-0029](决策/ADR-0029-主窗口与对话页对齐cc-bar的功能与布局.md)）。
- 用量页覆盖从未扫描、扫描中、部分失败、空数据源、存在未定价条目和数据库暂不可用六种情形，
  不把任何一种伪装成精确 `$0`。
- 主窗口分组侧边栏可完成视图切换与数据源过滤；进入设置隐藏数据源组；对话、时间线视图下数据源
  组保留且过滤生效（[ADR-0024](决策/ADR-0024-主窗口分组侧边栏导航.md)）。
- 主窗口不出现任何额度读数；额度异常的完整解释在某个表面可达（落脚点见
  [ADR-0020](决策/ADR-0020-主窗口改为本地用量页.md)「未解决问题」，未解决前本条不成立）。
- 对照本文件逐项验收，没有把后续能力悄悄带入首版。
