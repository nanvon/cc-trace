# CC Trace 文案与国际化

> 状态：首版基线
> 目标版本：`0.1.x`
> 基线日期：2026-07-25

本文件是 CC Trace 文案组织方式、i18n key 规范、时间与数字格式，以及错误文案目录的唯一来源。文案语气原则见 [设计方向与状态规范](设计方向与状态规范.md) 第 7.4 节；状态语义见 [状态与错误模型](状态与错误模型.md)。

## 1. 语言范围

| 项 | 首版 |
|---|---|
| 支持语言 | 简体中文 `zh-CN`、英文 `en` |
| 默认 | 跟随系统 |
| 用户可选 | 跟随系统、中文、English |
| 回退 | 缺失 key 回退到 `en`，不显示 key 名 |

规则：

- “跟随系统”的系统语言由 Rust 平台层提供并随设置一起下发，不在 Vue 里读 `navigator.language`。
- 语言选择保存在 CC Trace 自己的设置文件，切换后立即生效，不需要重启。
- 只有这两种语言进入首版；不为其他语言预留空文件。
- 所有用户可见字符串都必须来自 i18n，不允许在组件里硬编码任何一种语言。

### 1.1 当前实现偏差

Tray 桌面壳预览期的实现与本规范不一致，属已知技术债：

- `src/views/`、`src/components/` 与 `src/features/quota/preview.ts` 中的用户可见文案全部硬编码中文，没有走 i18n。
- `src/i18n/messages.ts` 只剩 `foundation.*` 一个命名空间，对应已被替换的工程基线页，属死代码。
- `src/i18n/index.ts` 用 `navigator.language` 判断语言，没有“跟随系统 / 手动选择”的区分，也没有持久化。

正式业务页面实现时必须一并修正，见 [桌面壳验证记录](桌面壳验证记录.md) 的“尚未完成”。

## 2. key 规范

按**表面**划分顶层命名空间，第二层按语义分组，键名用小驼峰：

```text
common      通用动作与词汇：refresh、settings、quit、retry、close、details
provider     Provider 名称与身份提示
quota        额度窗口、剩余、重置相关标签
status       状态词：live、stale、offline、rateLimited、loading
error        错误标题、影响与下一步，见第 4 节
compact      紧凑面板专属文案
main         主窗口专属文案
settings     设置窗口专属文案
onboarding   首次启动专属文案
a11y         纯无障碍文本：aria-label、屏幕阅读器说明
```

硬规则：

- **按语义命名，不按位置命名。** 用 `common.refresh`，不用 `compact.button1`。
- **不拼接句子。** 一条完整句子是一个 key；需要变量时用命名参数：`quota.resetsAt: "{time} 重置"`。
- 复数与计数使用 vue-i18n 的复数形式，不用 `if (n > 1)` 拼字符串。
- 状态词不写进句子模板里；句子引用状态 key，保证状态词只有一处译法。
- 同一概念只有一个 key：`refresh` 不允许同时存在 `refreshAll`、`doRefresh`、`refreshNow` 三个近义 key。
- 一个 key 只有一种语气，不因为出现在两个表面就复制两份。
- 删除功能时同时删除它的 key，不留死 key。

## 3. 时间与数字格式

### 3.1 数据形态

- Rust 下发的所有时刻是 ISO 8601 UTC 字符串，展示层负责本地化。
- 格式化统一使用 `Intl.DateTimeFormat` 与 `Intl.NumberFormat`，locale 取当前界面语言。
- 界面一律显示**本地时区**，不显示 UTC 标记，不做时区选择。

### 3.2 格式规则

| 内容 | 规则 | 中文示例 | 英文示例 |
|---|---|---|---|
| 剩余百分比 | 整数，四舍五入，`tabular-nums`；大于 0 但不足 1 显示 `<1%` | `37%` | `37%` |
| 重置时刻 | 主显示绝对本地时间；当天只显示时:分，跨天加日期 | `14:30 重置`、`7月26日 09:00 重置` | `Resets 14:30`、`Resets Jul 26, 09:00` |
| 重置相对时长 | 作为次级信息补充，精度到分钟或小时，不显示秒 | `约 3 小时后` | `in about 3 hours` |
| 最近成功刷新 | 相对时间为主；超过 24 小时改用绝对日期 | `刚刚`、`5 分钟前`、`7月24日` | `just now`、`5 min ago`、`Jul 24` |
| 可再次尝试 | 相对倒计时，精度到分钟；不足 1 分钟显示 `不到 1 分钟` | `4 分钟后可再试` | `retry in 4 min` |
| 窗口长度 | 用产品语言而非秒数 | `5 小时窗口`、`每周窗口` | `5-hour window`、`Weekly window` |

补充规则：

- 所有会变化的数字使用 `font-variant-numeric: tabular-nums`，宽度不得随刷新跳动。
- 相对时间必须同时提供绝对值：通过 `title` 或 `aria-label` 暴露完整本地时间。
- 相对时间不做秒级自动跳字；随刷新周期或状态变化更新即可。
- `resetsAt` 缺失时显示“重置时间未知”，不显示占位符号或猜测值。
- 中文数字与单位之间不加空格，英文加空格。

## 4. 错误与状态文案目录

紧凑面板用一行短说明；主窗口用**标题 / 影响 / 下一步**三级结构。下表是首版必须覆盖的全集，与 [状态与错误模型](状态与错误模型.md) 第 4 节一一对应。

| 状态 | 中文标题 | 中文下一步 | English title | English next step |
|---|---|---|---|---|
| `loading` + 无快照 | 正在检查额度 | — | Checking quota | — |
| `refreshing` + 有快照 | 正在刷新，显示上一份数据 | — | Refreshing, showing last data | — |
| `live` | 额度状态正常 | — | Quota is healthy | — |
| `stale` | 显示的是旧数据 | 刷新以获取最新额度 | Showing older data | Refresh to get the latest quota |
| `no_credentials` | 未发现可用凭据 | 在对应 CLI 登录后刷新 | No credentials found | Sign in with the CLI, then refresh |
| `unsupported` | 凭据形式暂不支持 | 首版只支持自动发现的 OAuth 凭据 | Credential type not supported | This release supports auto-discovered OAuth credentials only |
| `offline` + 有快照 | 当前离线，显示旧数据 | 网络恢复后刷新 | Offline, showing older data | Refresh once you are back online |
| `offline` + 无快照 | 当前离线，没有可显示的额度 | 检查网络后重试 | Offline, no quota to show | Check your connection and retry |
| `rate_limited` | 刷新受限 | 冷却结束后可再次刷新 | Refresh rate-limited | You can refresh again after the cooldown |
| `error` 凭据类 | 凭据已失效 | 在对应 CLI 重新登录 | Credentials are no longer valid | Sign in again with the CLI |
| `error` 协议类 | 无法读取额度数据 | 稍后重试；持续出现请更新 CC Trace | Could not read quota data | Try again later; update CC Trace if it persists |

“影响”一句由状态与数据组合决定，例如“Codex 额度仍可查看，Claude Code 显示的是 2 小时前的数据”。它必须说明**用户实际损失了什么**，不重复标题。

### 4.1 文案禁止事项

- 不道歉，不写“抱歉”“很遗憾”。
- 不用“未知错误”“出错了”作为最终解释。
- 不暴露 Rust 枚举名、HTTP 状态码原文、请求头、文件绝对路径、token 或邮箱。
- 不用感叹号，不用营销语气，不用“智能”“无缝”“强大”这类空词。
- 不把技术动作当用户动作：写“在 Codex CLI 登录”，不写“刷新 OAuth token”。
- 不在紧凑面板展开长错误；紧凑面板一行，完整解释留给主窗口。
- 不用“请稍后重试”作为唯一下一步，除非确实没有别的可执行动作。

## 5. 无障碍文本

- 图标按钮必须有 `a11y.*` 下的可访问名称，不依赖 Tooltip。
- 进度轨道提供文本等价：无可用额度时读作“无可用额度”，不读成 `0%`。
- 状态变化通过节制的 `aria-live` 区域播报；不重复播报无变化的刷新结果。
- 长账号名与长模型名单行省略时，完整值必须可被辅助技术获取。

## 6. 翻译与验收

- 中文与英文同时提交，不允许只写一种语言就合并。
- 英文使用句首大写，不使用全大写标签（除已确认的极短稳定标签）。
- 每个新增 key 必须在两种语言下检查：长度、换行、是否遮挡额度与恢复动作。
- 200% 文字缩放下第 4 节全部文案必须仍然完整可读，见 [测试策略](测试策略.md) 第 4 节。
