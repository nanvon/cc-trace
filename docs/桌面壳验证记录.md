# Tauri Tray 桌面壳验证记录

> 状态：macOS 实机通过，Windows 待实机验证
> 基线日期：2026-07-25

## 实现范围

当前实现只验证桌面壳，不接入任何 Provider：

- Rust 创建并持有 Tauri 2 Tray Icon 与原生菜单。
- Rust 管理紧凑窗口、主窗口和设置窗口的显示、聚焦、隐藏与退出。
- Vue 使用同一份合成额度数据展示紧凑入口和主窗口。
- 设置窗口只验证独立窗口职责，所有选项均不持久化。
- 不读取凭据、外部日志、旧 cc-bar 数据或真实额度。
- 不创建 Provider 请求、缓存、调度、429 退避或安全存储。

## Rust 与 Vue 边界

| 能力 | 所属层 |
|---|---|
| Tray Icon、原生菜单、主点击事件 | Rust |
| 窗口显示、聚焦、失焦隐藏、关闭不退出 | Rust |
| macOS 模板图标与 Windows Bundle Icon | Rust 平台分支 |
| 紧凑入口、主窗口、设置窗口内容 | Vue |
| 桌面壳合成快照与刷新动画 | Vue |
| “查看详情”“设置”“退出”请求 | Vue 调用窄 Tauri command |

前端没有取得任意窗口创建、通用文件系统、Shell、HTTP 或秘密读取能力。Capability 仍只有三个已声明窗口的 `core:default`。

## 系统入口

### macOS

- 使用 `ActivationPolicy::Accessory`，运行时不额外占用 Dock。
- 使用 CC Trace Tray Symbol 的 RGBA 模板图标，随 Menu Bar 外观着色。
- 左键松开时打开／关闭紧凑窗口。
- 紧凑窗口按 Tray 点击位置定位，并在当前显示器工作区内约束。
- 失焦时自动隐藏紧凑窗口。
- 右键显示原生菜单。

### Windows

- 使用应用 Bundle Icon 作为 System Tray 图标。
- 使用与 macOS 相同的左键紧凑入口语义。
- 使用右键原生菜单。
- 紧凑窗口定位到 Tray 点击点上方，并约束在当前显示器工作区。

Windows 分支已经编译进条件代码，但本轮没有 Windows 主机，因此不得把它标记为实机通过。

## 原生菜单

原生菜单固定包含：

1. 打开 CC Trace
2. 刷新额度
3. 设置
4. 退出 CC Trace

“刷新额度”当前只广播桌面壳预览事件，不调用 Provider。正式 Provider 接入后，应由同名业务用例替换，不保留第二套刷新状态源。

## 窗口策略

| 窗口 | 初始状态 | 关键行为 |
|---|---|---|
| `compact` | 隐藏 | 无装饰、不可缩放、置顶、不进任务栏、失焦隐藏 |
| `main` | 隐藏 | 打开已存在实例并聚焦；关闭时隐藏，进程继续驻留 |
| `settings` | 隐藏 | 打开已存在实例并聚焦；关闭时隐藏，进程继续驻留 |

打开主窗口或设置窗口前会先隐藏紧凑窗口。三个窗口都由配置预创建，重复操作不会创建第二个实例。

## macOS 实机结果

2026-07-25 在当前 macOS 主机完成：

- 菜单栏显示清晰的 CC Trace 模板图标。
- 左键打开紧凑额度窗口，窗口锚定在图标下方。
- 再次点击或点击外部可关闭紧凑窗口。
- 紧凑窗口显示 Codex、Claude Code 同一份合成额度数据。
- “查看详情”关闭紧凑窗口并打开主窗口。
- 右键显示原生菜单，菜单项顺序和职责正确。
- 原生菜单可以打开独立设置窗口。
- 关闭设置窗口后进程和 Tray Icon 继续存在。
- `cargo check` 通过。
- `pnpm build`（包含 `vue-tsc --noEmit`）通过。
